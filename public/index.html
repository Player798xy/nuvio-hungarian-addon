Hogyan add hozzá Nuvio és Stremio alkalmazásokhoz?
  1. Stremio-ban: Kattints a fenti kék "Telepítés Stremio-ba" gombra. Az alkalmazás azonnal megnyílik, ahol csak egy megerősítő Install gombot kell nyomnod.
  2. Nuvio-ban (TV, PC vagy telefon): Kattints a "Nuvio Link Másolása" gombra.
  3. Nyisd meg a Nuvio appot ➔ menj a Settings (Beállítások) ➔ Addons (Kiegészítők) menübe.
  4. Kattints az Add Addon lehetőségre, illeszd be a kimásolt Manifest linket, és nyomj a Telepítés gombra.
  5. Kész! Azonnal megjelenik a 🔴 Magyar Élő TV, valamint a filmeknél és sorozatoknál a közvetlen magyar szinkronos streamek.
